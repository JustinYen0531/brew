來源櫃

這裡只處理材料從哪裡來：推薦來源、指定社群、網址限制與給採編室的備註。主題與閱讀風格，回到「我的配方」調整。

來源探索資料庫

這份主配方有自己的十個推薦來源。輸入任何字，系統會先查來源資料庫，再視需要找新的提供者；你選取的是來源，不是把自己知道的名字硬塞進 prompt。

載入推薦來源中…
來源會顯示品質、影響力、訊號與可近性評分；這些是排序證據，不是永遠不變的排名。

來源出現機會

這是偏好，不是硬性命令。1 代表盡量少出現，3 是正常，5 代表希望多遇到這類來源。

新增來源到配方

找不到你想追的媒體、軟體、論壇、頻道或社群時，可以新增一個可開啟的 URL；它會保存到你的個人配方，之後也會參與排序。

額外 prompt 配方

每次呼叫時都會重新讀取這段話，適合描述你最近想追的主題或排除條件。

直接資訊來源網址

這裡是硬性規定。填入後，該次手沖只從這些網址或其頁面翻找；一行一個網址。

資訊源頭語言

目前支援中文或英文；這會影響來源搜尋時優先尋找哪種語言，不會改變這個中文介面的閱讀語言。

生成方式

選擇這次手沖使用的編輯引擎。OpenAI API 適合網站自動執行；本機 Codex 會在你的電腦上呼叫已登入 ChatGPT 的 Codex CLI，不能由雲端網站代跑。

你自己的 API Key

手動生成晨報時，可以使用你自己的 OpenRouter 或 OpenAI API Key。它只保存在這個瀏覽器的本機資料裡，不會同步到 Supabase、帳號配方或日報檔案；真正生成時才會暫時傳給目前的手沖服務。共用電腦請不要保存。

選「本機 Codex（訂閱）」不需要填 Key。清除網站資料、換瀏覽器或換裝置後，這裡的 Key 不會自動跟著走。
