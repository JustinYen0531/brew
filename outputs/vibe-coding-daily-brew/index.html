來源與語言設定

偏好

每次手沖前，會把這些偏好放進編輯 prompt；它們只影響下一次找什麼、怎麼找。

來源探索資料庫

打開這個偏好區塊就會先顯示 10 個推薦來源。輸入任何字，系統會用資料庫別名與即時網路搜尋猜你想找的提供者；你選取的是來源，不是把自己知道的名字硬塞進 prompt。

載入推薦來源中…
來源會顯示品質、影響力、訊號與可近性評分；這些是排序證據，不是永遠不變的排名。

新增來源偏好

找不到你想追的媒體、軟體、論壇、頻道或社群時，可以新增一個可開啟的 URL；它會保存到你的個人偏好，之後也會參與排序。

額外 prompt 偏好

每次呼叫時都會重新讀取這段話，適合描述你最近想追的主題或排除條件。

直接資訊來源網址

這裡是硬性規定。填入後，該次手沖只從這些網址或其頁面翻找；一行一個網址。

資訊源頭語言

目前支援中文或英文；這會影響來源搜尋時優先尋找哪種語言，不會改變這個中文介面的閱讀語言。

生成方式

選擇這次手沖使用的編輯引擎。OpenAI API 適合網站自動執行；本機 Codex 會在你的電腦上呼叫已登入 ChatGPT 的 Codex CLI，不能由雲端網站代跑。
